# План: сотрудники, наряды, поломки (Блок F)

Спецификация: `docs/superpowers/specs/2026-11-24-staff-and-work-orders-design.md`

Пять историй, три части.

## Часть 1. US-47 — роли и область прав

- [ ] Миграция: `Role`, `Employee` и перечень прав.
- [ ] `staff-service.ts`: приглашение, смена роли и области, снятие,
      `can(employee, permission, pointId?)`, предустановленные роли §47.
- [ ] Тесты `staff-service.test.ts`.
- [ ] Кабинет сети: сотрудники, роли, область по пунктам.
- [ ] Список пунктов и мастер уважают область.
- [ ] Ключи en/ru/sk. Прогон, сборка, коммит.

## Часть 2. US-48 и US-54 — наряды

- [ ] Миграция: `WorkOrder` со статусами §48.
- [ ] `work-order-service.ts`: создание из аварии, из заявки, руками;
      без двойников; переходы статусов; назначение.
- [ ] Тесты `work-order-service.test.ts`.
- [ ] Воркер раз в минуту: наряд по открытой аварии, письмо инженеру.
- [ ] Страница нарядов инженера и карточка наряда.
- [ ] Ключи en/ru/sk. Прогон, сборка, коммит.

## Часть 3. US-52 и US-53 — сообщение о поломке

- [ ] Миграция: `Ticket` с полями §51.
- [ ] `ticket-service.ts`: заявка, техническая поломка заводит наряд и
      выводит разъём из строя, подбор ближайших рабочих станций.
- [ ] Тесты `ticket-service.test.ts`.
- [ ] Форма `/c/[id]/report` в одно нажатие и предложение станции.
- [ ] Очередь заявок в кабинете сети.
- [ ] Ключи en/ru/sk. Прогон, сборка, коммит.
