# План: пульт станции (Блок D)

Спецификация: `docs/superpowers/specs/2026-11-24-station-console-design.md`

Четыре истории, три части, каждая со своим коммитом и отчётом владельцу.

## Часть 1. US-18 и US-26 — пульт: выработка, график, доход

- [x] Миграция: `EnergyToken.soldTradeId`.
- [x] Расчёт сделки проставляет `soldTradeId` переданным партиям.
- [x] `station-service.ts`: выработка сейчас и за периоды, точки графика
      (день по интервалам, неделя и месяц по дням), свежесть данных, свод
      по токенам, доход и средняя цена продажи.
- [x] Тесты `station-console.test.ts`.
- [x] Страница `/me/listing/[companyId]/assets/[assetId]` — виджеты §30 и
      график; ссылка с карточки объекта.
- [x] Клиентская обвязка: канал `telemetry.{asset}` плюс обновление раз в
      60 секунд (US-26).
- [x] Ключи en/ru/sk. Прогон, сборка, коммит.

## Часть 2. US-28 — правила продажи и резерв заряда

- [x] Миграция: `Asset.reserveSocPct`.
- [x] `dispatch-service.ts`: заявка на продажу рыночной доли интервала по
      `minSalePrice` или спотовому ориентиру; детерминированный ключ
      идемпотентности; накопитель не предлагает ниже резерва.
- [x] Тесты `dispatch-service.test.ts`.
- [x] Воркер вызывает диспетчер после закрытия интервала.
- [x] Форма правил продажи на пульте: минимальная цена, доли, резерв заряда;
      запись в журнал.
- [x] Ключи en/ru/sk. Прогон, сборка, коммит.
