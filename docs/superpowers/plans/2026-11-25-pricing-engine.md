# Тарифный движок — план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development
> или superpowers:executing-plans.

**Goal:** любое изменение тарифа версионируется, напечатанный чек не меняется
задним числом, у платформы есть тарифные планы партнёров (§52–54).

**Architecture:** спецификация `docs/superpowers/specs/2026-11-25-pricing-engine-design.md`.
`PricingRule` — неизменяемый журнал версий, который пишется в той же транзакции,
что и живая таблица. Оплата запоминает версию тарифа; чек читает её, а не
живые строки.

**Tech Stack:** Next.js 16 App Router, Prisma, Postgres, vitest, Playwright.

Тесты только против `poolwatt_test`:
`NODE_ENV=test DATABASE_URL="$(sed -n 's/^DATABASE_URL=//p' .env.local | tr -d '"' | sed 's|/poolwatt?|/poolwatt_test?|')" npx vitest run <путь>`
