# Внутренний чат команды и чат по наряду — план (N-4, §48)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan
> task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** сотрудники сети разговаривают внутри платформы — в комнате сети, в
комнате бригады и в чате каждого наряда, — а чат наряда ещё и рассказывает
его историю системными строками и принимает сообщение, написанное без связи.

**Architecture:** комната — это существующая строка (`ChargerOperator`,
`Crew`, `WorkOrder`) плюс append-only `ChatMessage`; ключ комнаты
(`net-…`, `crew-…`, `wo-…`) он же имя шестого канала §15 `team.<ключ>`;
право на комнату считает один модуль `chat-access.ts`, и для наряда он зовёт
существующий `readWorkOrderForUser`; отправка идемпотентна, потому что
офлайн-досыл §48 — это повтор.

**Tech Stack:** Next.js 16 (App Router), Prisma, vitest, Playwright
(проекты по умолчанию и `mobile`, Pixel 7), next-intl v4, Redis (§15).

Спецификация: `docs/superpowers/specs/2026-11-28-team-chat-design.md`.

/// переписка о наряде — часть его истории, и переписанное задним числом

model ChatMessage {
  id          String           @id @default(cuid())
  kind        ChatRoomKind
  operatorId  String?
  operator    ChargerOperator? @relation(fields: [operatorId], references: [id], onDelete: Cascade)
  crewId      String?
  crew        Crew?            @relation(fields: [crewId], references: [id], onDelete: Cascade)
  workOrderId String?
  workOrder   WorkOrder?       @relation(fields: [workOrderId], references: [id], onDelete: Cascade)
  authorKind  ChatAuthorKind   @default(STAFF)
  authorId    String?
  author      User?            @relation("ChatMessageAuthor", fields: [authorId], references: [id], onDelete: SetNull)
  body        String           @db.Text
  createdAt   DateTime         @default(now())

  @@index([operatorId, createdAt])
  @@index([crewId, createdAt])
  @@index([workOrderId, createdAt])
}

/// Одна отметка на человека и комнату: всё новее неё — непрочитанное.
model ChatRead {
  id      String   @id @default(cuid())
  userId  String
  user    User     @relation("ChatReadUser", fields: [userId], references: [id], onDelete: Cascade)
  roomKey String
  seenAt  DateTime @default(now())

  @@index([userId])

```ts
// Ключ комнаты §48 — одна строка, она же имя канала §15.
//
// Комнат три вида, и ни одна не существует как отдельная строка в базе:
// комната — это сеть, бригада или наряд плюс их сообщения. Ключ поэтому
// составной, и собирать его руками в двух местах нельзя: имя канала у
// страницы и у публикатора должно совпадать до буквы.

import type { ChatRoomKind } from "@prisma/client";

export interface RoomRef {
  kind: ChatRoomKind;
  id: string;
}

const PREFIX: Record<ChatRoomKind, string> = {
  NETWORK: "net",
  CREW: "crew",
  WORK_ORDER: "wo",
};

export function roomKey(ref: RoomRef): string {
  return `${PREFIX[ref.kind]}-${ref.id}`;
}

/** Ключ из адреса или из тела запроса — чужой строке здесь веры нет. */
export function parseRoomKey(key: string): RoomRef | null {
  const dash = key.indexOf("-");
  if (dash <= 0) return null;
  const prefix = key.slice(0, dash);
  const id = key.slice(dash + 1);
  // Идентификатор cuid — буквы и цифры; длину ограничиваем, потому что ключ
  // едет в имя канала §15, а оно проверяется по длине.
  if (!/^[A-Za-z0-9_]{1,60}$/.test(id)) return null;
  const kind = (Object.keys(PREFIX) as ChatRoomKind[]).find((k) => PREFIX[k] === prefix);
  return kind ? { kind, id } : null;
}

export const chatChannel = (key: string) => `team.${key}`;
```

```ts
// Кто в комнате §48. Один ответ на вопрос «чья это переписка».
//
// Комната наряда не отвечает сама: она зовёт `readWorkOrderForUser`. Второй
// ответ на вопрос «чей это наряд» однажды разойдётся с первым — и разойдётся
// в сторону «да», как было с `tickets.write` до N-1.

import { prisma } from "@/lib/prisma";
import { can, readEmployee } from "@/lib/staff/staff-service";
import { parseRoomKey, type RoomRef } from "./chat-rooms";
import { readWorkOrderForUser } from "./work-order-access";

export interface RoomView {
  key: string;
  ref: RoomRef;
  title: string;
  /** Читать можно всегда, когда комната вернулась: иначе null. */
  canWrite: boolean;
}

export async function readRoomForUser(
  key: string,
  userId: string,
  role: string,
): Promise<RoomView | null> {
  const ref = parseRoomKey(key);
  if (!ref) return null;

  if (ref.kind === "WORK_ORDER") {
    const seen = await readWorkOrderForUser(ref.id, userId, role);
    if (!seen) return null;
    // Писать может всякий, кто видит наряд: сказать инженеру «ворота с
    // обратной стороны» — не работа в наряде, а разговор о ней.
    return { key, ref, title: seen.order.title, canWrite: true };
  }

  if (ref.kind === "NETWORK") {
    const operator = await prisma.chargerOperator.findUnique({
      where: { id: ref.id },
      select: { id: true, displayName: true, claimedById: true },
    });
    if (!operator) return null;
    if (role === "ADMIN" || operator.claimedById === userId) {
      return { key, ref, title: operator.displayName, canWrite: true };
    }
    // Любая роль §47: права «чат» в §47 нет, и выдумывать его нельзя —
    // бухгалтер и маркетолог тоже команда.
    const employee = await readEmployee(operator.id, userId);
    if (!employee) return null;
    return { key, ref, title: operator.displayName, canWrite: true };
  }

  const crew = await prisma.crew.findUnique({
    where: { id: ref.id },
    select: {
      id: true,
      name: true,
      operatorId: true,
      operator: { select: { claimedById: true } },
      members: { select: { employee: { select: { userId: true } } } },
    },
  });
  if (!crew) return null;
  if (role === "ADMIN" || crew.operator.claimedById === userId) {
    return { key, ref, title: crew.name, canWrite: true };
  }
  if (crew.members.some((m) => m.employee.userId === userId)) {
    return { key, ref, title: crew.name, canWrite: true };
  }
  // Диспетчер назначает бригаде наряд, значит должен с ней говорить.
  const employee = await readEmployee(crew.operatorId, userId);
  if (!employee || !can(employee, "workorders.read")) return null;
  return { key, ref, title: crew.name, canWrite: true };
}
```

// Чат §48: отправка, системная запись, чтение, список комнат и
// непрочитанное.
//
// Три решения:
//
// 1. Право спрашивается здесь, а не на странице: служба — единственный вход,
//    и чужая комната отвечает отказом, а не пустым списком.
// 2. Живая доставка не роняет запись: канал молчит — сообщение всё равно в
//    базе, страница увидит его при следующей загрузке (как у заявок §51).
// 3. Своё сообщение непрочитанным не бывает, поэтому отметка «прочитано»
//    ставится и при отправке.

import type { ChatMessage, ChatRoomKind, Prisma } from "@prisma/client";
import { prisma } from "@/lib/prisma";
import type { Db } from "@/lib/exchange/audit";
import { publish } from "@/lib/exchange/realtime";
import { chatChannel, parseRoomKey, roomKey, type RoomRef } from "./chat-rooms";
import { readRoomForUser } from "./chat-access";

export class ChatError extends Error {}

export const MAX_CHAT_MESSAGE_LENGTH = 4000;
/** Сколько сообщений отдаёт страница: чат наряда короток, сети — нет. */
export const PAGE_SIZE = 200;

export interface ChatMessageView {
  id: string;
  authorKind: "STAFF" | "SYSTEM";
  authorName: string | null;
  mine: boolean;
  body: string;
  at: string;
}

export interface MyRoom {
  key: string;
  kind: ChatRoomKind;
  title: string;
  /** Подпись под названием: город пункта, сеть бригады, статус наряда. */
  note: string | null;
  unread: number;
  lastAt: string | null;
}

const where = (ref: RoomRef): Prisma.ChatMessageWhereInput =>
  ref.kind === "NETWORK"
    ? { kind: "NETWORK", operatorId: ref.id }
    : ref.kind === "CREW"
      ? { kind: "CREW", crewId: ref.id }
      : { kind: "WORK_ORDER", workOrderId: ref.id };

const link = (ref: RoomRef) =>
  ref.kind === "NETWORK"
    ? { kind: "NETWORK" as const, operatorId: ref.id }
    : ref.kind === "CREW"
      ? { kind: "CREW" as const, crewId: ref.id }
      : { kind: "WORK_ORDER" as const, workOrderId: ref.id };

export async function postChatMessage(args: {
  key: string;
  userId: string;
  role: string;
  body: string;
}): Promise<ChatMessage> {
  const body = args.body.trim();
  if (body.length === 0) throw new ChatError("A message needs words");
  if (body.length > MAX_CHAT_MESSAGE_LENGTH) throw new ChatError("The message is too long");

  const room = await readRoomForUser(args.key, args.userId, args.role);
  if (!room?.canWrite) throw new ChatError("No such room");

  const message = await prisma.chatMessage.create({
    data: { ...link(room.ref), authorKind: "STAFF", authorId: args.userId, body },
  });
  // Своё сообщение прочитано по определению.
  await touchRead(args.key, args.userId, message.createdAt);
  await announce(args.key, message, null);
  return message;
}

/** Факт, о котором говорит сама платформа: назначение, смена статуса. */
export async function systemChatMessage(
  db: Db,
  ref: RoomRef,
  body: string,
): Promise<ChatMessage> {
  const message = await db.chatMessage.create({
    data: { ...link(ref), authorKind: "SYSTEM", body: body.trim() },
  });
  await announce(roomKey(ref), message, null);
  return message;
}

export async function readRoomMessages(
  key: string,
  userId: string,
  role: string,
): Promise<ChatMessageView[]> {
  const room = await readRoomForUser(key, userId, role);
  if (!room) throw new ChatError("No such room");
  const rows = await prisma.chatMessage.findMany({
    where: where(room.ref),
    orderBy: { createdAt: "asc" },
    take: PAGE_SIZE,
    include: { author: { select: { id: true, username: true } } },
  });
  return rows.map((row) => ({
    id: row.id,
    authorKind: row.authorKind,
    authorName: row.author?.username ?? null,
    mine: row.authorId === userId,
    body: row.body,
    at: row.createdAt.toISOString(),
  }));
}

export async function markRoomSeen(key: string, userId: string, role: string): Promise<void> {
  const room = await readRoomForUser(key, userId, role);
  if (!room) throw new ChatError("No such room");
  await touchRead(key, userId, new Date());
}

/** Комнаты этого человека: сеть, бригады, открытые наряды. */
export async function listMyRooms(userId: string, role: string): Promise<MyRoom[]> {
  // Сотрудником можно быть в нескольких сетях; владелец сети сотрудником не
  // является, поэтому его сети берутся отдельно.
  const [employments, owned, crews, orders, reads] = await Promise.all([
    prisma.employee.findMany({
      where: { userId },
      select: { operatorId: true, operator: { select: { displayName: true } } },
    }),
    prisma.chargerOperator.findMany({
      where: { claimedById: userId },
      select: { id: true, displayName: true },
    }),
    prisma.crew.findMany({
      where: { OR: [{ members: { some: { employee: { userId } } } }, { operator: { claimedById: userId } }] },
      select: { id: true, name: true, operator: { select: { displayName: true } } },
    }),
    prisma.workOrder.findMany({
      where: {
        closedAt: null,
        OR: [
          { assignee: { userId } },
          { crew: { members: { some: { employee: { userId } } } } },
        ],
      },
      select: { id: true, title: true, status: true },
    }),
    prisma.chatRead.findMany({ where: { userId }, select: { roomKey: true, seenAt: true } }),
  ]);

  const seen = new Map(reads.map((r) => [r.roomKey, r.seenAt]));
  const refs: { ref: RoomRef; title: string; note: string | null }[] = [];
  const networks = new Map<string, string>();
  for (const e of employments) networks.set(e.operatorId, e.operator.displayName);
  for (const o of owned) networks.set(o.id, o.displayName);
  for (const [id, title] of networks) refs.push({ ref: { kind: "NETWORK", id }, title, note: null });
  for (const c of crews)
    refs.push({ ref: { kind: "CREW", id: c.id }, title: c.name, note: c.operator.displayName });
  for (const o of orders)
    refs.push({ ref: { kind: "WORK_ORDER", id: o.id }, title: o.title, note: o.status });

  return Promise.all(
    refs.map(async (row) => {
      const key = roomKey(row.ref);
      const base = where(row.ref);
      const after = seen.get(key);
      const [unread, last] = await Promise.all([
        prisma.chatMessage.count({
          where: {
            ...base,
            ...(after ? { createdAt: { gt: after } } : {}),
            NOT: { authorId: userId },
          },
        }),
        prisma.chatMessage.findFirst({
          where: base,
          orderBy: { createdAt: "desc" },
          select: { createdAt: true },
        }),
      ]);
      return {
        key,
        kind: row.ref.kind,
        title: row.title,
        note: row.note,
        unread,
        lastAt: last?.createdAt.toISOString() ?? null,
      };
    }),
  );
}

/** Одно число для хаба §22. */
export async function unreadTotal(userId: string, role: string): Promise<number> {
  const rooms = await listMyRooms(userId, role);
  return rooms.reduce((sum, room) => sum + room.unread, 0);
}

async function touchRead(key: string, userId: string, at: Date): Promise<void> {
  await prisma.chatRead.upsert({
    where: { userId_roomKey: { userId, roomKey: key } },
    create: { userId, roomKey: key, seenAt: at },
    update: { seenAt: at },
  });
}

async function announce(key: string, message: ChatMessage, authorName: string | null): Promise<void> {
  if (!parseRoomKey(key)) return;
  try {
    await publish(chatChannel(key), "chat.message", {
      id: message.id,
      authorKind: message.authorKind,
      authorId: message.authorId,
      authorName,
      body: message.body,
      at: message.createdAt.toISOString(),
    });
  } catch {
    // Пропущенное событие стоит перезагрузки страницы, не записи.
  }
}

// GET|POST /v1/chat/rooms/{key}/messages — §48. POST идемпотентен: инженер
// пишет без связи, и досыл §48 — это повтор по определению.

import type { NextRequest } from "next/server";
import { z } from "zod";
import {
  fail,
  idempotencyKey,
  idempotent,
  notFound,
  ok,
  parseBody,
  sessionUser,
  unauthorized,
} from "@/lib/exchange/api";
import {
  ChatError,
  MAX_CHAT_MESSAGE_LENGTH,
  postChatMessage,
  readRoomMessages,
} from "@/lib/work/chat-service";

const schema = z.object({ body: z.string().trim().min(1).max(MAX_CHAT_MESSAGE_LENGTH) });

export async function GET(_req: NextRequest, { params }: { params: Promise<{ key: string }> }) {
  const { key } = await params;
  const user = await sessionUser();
  if (!user) return unauthorized();
  try {
    return ok({ messages: await readRoomMessages(key, user.id, user.role) });
  } catch (err) {
    if (err instanceof ChatError) return notFound();
    throw err;
  }
}

export async function POST(req: NextRequest, { params }: { params: Promise<{ key: string }> }) {
  const { key } = await params;
  const user = await sessionUser();
  if (!user) return unauthorized();

  const parsed = await parseBody(req, schema);
  if ("response" in parsed) return parsed.response;
  const b = parsed.data;

  try {
    return await idempotent({
      endpoint: `POST /v1/chat/rooms/${key}/messages`,
      key: idempotencyKey(req),
      userKey: user.id,
      body: b,
      run: async () => {
        const message = await postChatMessage({
          key,
          userId: user.id,
          role: user.role,
          body: b.body,
        });
        return { status: 201, data: { id: message.id, at: message.createdAt.toISOString() } };
      },
    });
  } catch (err) {
    if (err instanceof ChatError) return fail(err.message, 404);
    throw err;
  }
}

   владелец сети, ADMIN. Диспетчеру есть где сказать слово — чат наряда и
   комната сети.
2. **`chatChannel` вызывается из `chat-rooms.ts`, а не из `realtime.ts`.** В
   `realtime.ts` добавлено только разрешение имени: иначе модуль каналов
   начал бы знать про комнаты.
3. **Отметка «прочитано» ставится и при отправке** — иначе своё же сообщение
   считалось бы непрочитанным до следующего открытия комнаты.
4. **Отказ сети на мониторе говорит словами.** `ChatThread` ловит бросок
   серверного действия: на телефоне сообщение уходит в очередь, на мониторе
   человек читает «связи нет, сообщение не ушло». Для этого в словари
   добавлена строка `chat.offline`, которой в плане не было.
5. **Счётчик непрочитанного в хабе считается на самой странице хаба**, а не в
   `shell-context`: контекст читает каждый экран, а хаб открывают редко.
